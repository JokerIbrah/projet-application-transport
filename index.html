Ce fichier n'est pas l'application

La page que vous cherchez est app/static/index.html, et elle ne fonctionne pas en double-cliquant dessus : ses horaires viennent de l'API, il faut donc lancer le serveur.

Depuis la racine du dépôt, une fois seulement :

python -m gtfs_metz.loader

Puis, à chaque fois :

uvicorn app.main:app --reload

L'application est alors sur http://127.0.0.1:8000.

Voir le README pour l'installation complète.
